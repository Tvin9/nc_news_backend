NC News API

A small api that allows users to interact with articles and comments

Available endpoints

  • GET /api/topics

    Retrieve a list of all topics.

    Example response:

      
{
  "topics": [
    {
      "slug": "coding",
      "description": "Code is love, code is life"
    },
    {
      "slug": "football",
      "description": "FOOTIE!"
    },
    {
      "slug": "cooking",
      "description": "Hey good looking, what you got cooking?"
    }
  ]
}

  • POST /api/articles/:article_id/comments

    Posts a comment to an article by article id.

    Example request

    POST /api/articles/1/comments { author: 'butter_bridge', body: 'Rubbish!' }

    Example response:

      
{
 "comment":[ { author: 'butter_bridge', body: 'Rubbish!' }]
}

  • PATCH /api/articles/:article_id

    Ammends the votes on and article by id.

    Example request

    POST /api/articles/1/ { inc_votes: 1}

    Example response:

      
{
 "vote": [{
    article_title:
      "The People Tracking Every Touch, Pass And Tackle in the World Cup",
    body: "Itaque quisquam est similique et est perspiciatis reprehenderit voluptatem autem. 
    Voluptatem accusantium eius error adipisci quibusdam doloribus.",
    votes: 101,
    author: "tickle122",
    created_at: new Date(1590103140000),
  }]
}

  • DELETE /api/comments/:comment_id
